# 🎓 Sistema de Gestión de Matrículas - Grupo 3

## 📝 Descripción
Sistema diseñado para automatizar el proceso de matrícula de estudiantes en la Universidad Agraria del Ecuador. Gestiona desde la preinscripción hasta la generación de horarios y certificados, reduciendo tiempos de espera y errores manuales.

## 🎯 Objetivo
Desarrollar una plataforma web escalable que permita a estudiantes, docentes y administradores gestionar el proceso de matrícula de forma eficiente, transparente y trazable.

## ⚙️ Funcionalidades principales
1. **Registro y autenticación de usuarios** (estudiantes, docentes, administradores).
2. **Gestión de oferta académica** (carreras, materias, horarios).
3. **Proceso de matrícula** con verificación de requisitos y pagos.
4. **Generación de reportes** (actas, certificados, listados).
